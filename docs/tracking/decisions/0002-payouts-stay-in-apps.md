# 0002. 지급 실행은 각 사업 앱에 둔다

## 배경
- deetz(비전속 댄서), grigo-artist(전속 아티스트 월 정산), 원샷크루는 각자 계좌 검증·원천징수·지급 파일 흐름을 갖고 있다.
- ERP는 로그인 직원 전원이 재무 행을 읽는 구조다.

## 결정
- 지급 계산·계좌 정보·이체 실행은 각 앱에 그대로 둔다.
- ERP는 지급 예정·완료 결과를 읽고, 프로젝트에 연결해 보여 주기만 한다.
- 동일인이 여러 사업부에 있어도 지급 계좌·정산 신원을 자동으로 합치지 않는다.

## 검토한 대안
- **ERP에서 전사 지급을 실행한다**: 계좌번호·주민번호가 전 직원이 읽는 ERP로 들어온다. 각 앱의 검증된 정산 계산을 다시 만들어야 한다.

## 결과
- ERP에는 계좌번호·주민번호 원문을 저장할 수 없다.
- ERP의 지급 관련 수정 화면은 원본 앱으로 연결만 한다.
- 이 레포의 파트너 수익배분 정산 기능(`partner_settlements`)은 이 결정과 맞지 않아 쓰지 않는다.
