# 0007. 저장소를 공개로 유지한다

## 배경
- GitHub 저장소가 공개 상태다.
- 테스트 스크립트에 실제 로그인 비밀번호가 커밋된 사실이 확인됐다.

## 결정
- 대표 결정으로 저장소는 공개를 유지한다.
- 대신 커밋되는 모든 파일에 비밀번호·키·실제 계정 정보·개인정보를 두지 않는 것을 절대 규칙으로 한다.
- 이미 커밋된 비밀은 값을 교체해 무효화한다.

## 검토한 대안
- **비공개로 전환한다**: 노출 범위는 줄지만, 대표가 공개를 유지해야 한다고 판단했다.

## 결과
- 코드·문서·테스트·SQL 모두 누구나 읽는다는 전제로 쓴다. 테스트 계정 정보는 환경변수로만 주입한다.
- 운영 스키마(`schema_.sql`, 마이그레이션)와 권한 구조도 공개되어 있다. 그래서 서버·DB 권한 봉인이 더 급하다.
