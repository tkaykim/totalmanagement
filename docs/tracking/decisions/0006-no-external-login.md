# 0006. 회사 밖 사람은 ERP에 로그인하지 않는다

## 배경
- `artist`·`viewer` 역할, `/artist` 아티스트 화면, 프로젝트의 아티스트·파트너 공개 설정, 파트너 수익배분 정산이 만들어져 있다.
- 하지만 사용자와 데이터는 0건이다.
- 전속 아티스트 정산은 grigo-artist가 이미 월 정산서로 제공한다.

## 결정
- ERP 로그인은 재직 직원만 한다.
- 외부인용 기능은 쓰지 않으며 정리한다. 아티스트 정산 화면은 grigo-artist가 맡는다.

## 검토한 대안
- **아티스트 포털을 살려 grigo-artist와 이중 운영한다**: 정산 숫자의 정본이 둘이 된다.
- **ERP를 외부에도 열어 한 곳으로 모은다**: 재무 행 전원 열람 구조라 외부인 권한을 따로 설계해야 하고, 노출 위험이 크다.

## 결과
- 외부인 계정을 전제로 한 권한 분기를 새로 만들지 않는다.
- 외부인용 화면·라우트는 정리 대상이다. 테이블 삭제는 별도 승인 사항이다.
